Deterministic Governance Framework (By-Law SEC-802)

CBSE Norm 14.2 Compliant

HanuJai High School operates zero predictive, probabilistic, or opaque algorithms in academic surveillance. Every student on this watchlist is enrolled through strictly observable, auditable conditions approved by the Academic Council:

01. RULE-ATT-75 / CBSE Floor
Triggers when cumulative instructional attendance falls below 75.0% without proctor-verified medical exemption on file.
02. RULE-ACAD-MULTI / Core Deficit
Triggers when a candidate scores <40% in two or more primary board core subjects in any scheduled term examination.
03. RULE-DECL-10 / Aggregate Drop
Triggers when the composite marks percentage decreases by ≥10.0% compared to the immediate prior baseline period.
04. RULE-ABS-CONSEC / Absence Run
Triggers when a student accumulates 5 or more unexcused consecutive absent days within a 14-day instructional window.
